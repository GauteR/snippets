# Snippets

Class-filtered **macro snippet templates** for **World of Warcraft: Forever**.

Browse templates for your current class, preview the expanded macro, and create it in the Blizzard macro list with one click.

## Features

- Templates filtered to your logged-in class
- **PvE** / **PvP** filters (`general` templates appear in both)
- Race lines expanded automatically when present in the template
- Preview is editable before you create
- Created macros persist in the Blizzard macro UI

## Install

1. Install via CurseForge / your preferred client, **or** copy the `snippets` folder to:

   `World of Warcraft\_forever_\Interface\AddOns\snippets`

2. Restart the client or log out and back in.
3. Enable **Snippets** on the character addon list if needed.

**Requires Forever** (`Interface` 16001 / 1.60.x). Not for Classic Era or Retail.

## How to use

1. Log in on the character you want macros for.
2. Type `/snippets` in chat.
3. Choose **PvE** or **PvP**.
4. Select a snippet, check the **Preview**, edit if you want.
5. Click **Create Macro**.
